# Prairiehearth Craft Supply — Fibre Pipeline Reference (Sample)

> Sample corpus notice. This document is a fictional grounding artifact for the Prairiehearth Craft Supply Co. pack. Cooperative names, dye-lot rules, and thresholds below are illustrative and not benchmarks.

## Cooperative Supplier Model

Prairiehearth sources yarn, weaving fibre, and paper stock from a small cooperative-supplier network of independent maker cooperatives. Each cooperative ships in fixed weekly cadences into a regional cross-dock; from there, workshop-anchored stores draw against a rolling allocation.

## Dye-Lot Integrity

Dye lots are the single loudest signal in the fibre category. A "dye lot" is the batch identifier under which a fibre run was coloured — because natural-fibre lots vary meaningfully between runs, a project-in-progress cannot be completed with mid-run substitutions without visible shifts.

A dye-lot shortfall inside an active workshop or maker project is treated as a top-severity supply event. Fibre Pipeline flags any store whose active dye-lot depth drops below a two-project floor for a headline yarn brand.

## Warp vs. Weft Stock

Loomshire Weaving inventory is split across warp and weft SKUs. Warp stock is the more supply-critical of the two — a warp shortfall halts the loom project entirely, whereas a weft substitution is often visually acceptable. Prairie Belt stores overweight warp stock relative to the platform mean.

## Vocabulary

- **Cooperative** — an independent maker cooperative that supplies fibre or paper stock.
- **Cross-dock** — the regional facility that receives cooperative shipments and allocates to stores.
- **Dye lot** — the batch identifier under which a fibre run was coloured.
- **Dye-lot depth** — the number of projects a store's remaining lot could complete before running out.
- **Warp shortfall** — a stockout on warp yarn that halts an active loom project.
