📦 Content packs packs/<pack>/

One directory holds the tenant model, agent roster, starting tasks and knowledge corpus. Packs:Active selects it at boot.
  • default (Apex Retail Group) · halcyon-pet-supply · prairiehearth-craft-supply
  • A load-time validator refuses to start if an agent definition breaks the safety rules
Azure

🚀 Hosting required

  • Container Apps — API, MCP server, Teams bot; managed identity, scale to zero
  • Container Registry — images pulled with managed identity, no admin secrets
  • Static Web Apps — serves the React build

🛡️ APIM AI Gateway required

Every LLM call routes through it — there is no direct-to-Azure-OpenAI path, and a deployment test enforces that.
  • Token limit 80,000 TPM per subscription
  • Token metrics to App Insights · LLM request/response logging
  • Circuit breaker on 429 · managed identity to Foundry
  • Operations: createChatCompletion, listModels

🧠 Azure AI Foundry required

Chat completions behind the gateway
  • gpt-5.4-mini deployment
  • Model-agnostic through IChatClient

🔑 Microsoft Entra ID required

The only auth mode ever deployed to production
  • Single tenant, PKCE; SPA and API registrations
  • RetailPulse.User app role on every request
  • Optional app-only tokens for machine callers, off by default

📊 Observability required

  • Application Insights + Log Analytics (OpenTelemetry)
  • Aspire dashboard locally
  • End-to-end traces: request → router → agent → tool → LLM

➕ Opt-in services optional

The platform runs fully without any of these
  • Azure AI Search — vector + BM25 knowledge
  • Azure AI Foundry IQ — hosted retrieval agent
  • Content Safety + Prompt Shields — input/output filtering
  • Foundry Agent Service — hosted shipment specialist
  • Synthetic chat monitor — federated, non-interactive smoke test
Required — provisioned by infra/main.bicep on every deployment
Optional — enabled by configuration; absent by default
Agents & tenants are data — YAML in packs/, no C# change
Charts — built from tool data, not model output
